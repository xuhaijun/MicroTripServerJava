# 中间件运维速查（MySQL / Redis / Java 服务）

> 目标：本机开发 & 联调时，随时查看 / 启动 / 停止 / 排查 MySQL、Redis 与 Java 后端服务。
> 相关文档：`本地环境运维手册.md`、`数据库操作指南.md`、`SQL通用模板.md`、IntelliJ 指南。

## 0. 速查总表

| 组件 | 服务名 | 端口 | 看状态 | 启动 | 停止 | 备注 |
|---|---|---|---|---|---|---|
| MySQL | `MySQL84` | 3306 | `sc query MySQL84` | `net start MySQL84` | `net stop MySQL84` | 数据目录 `D:/mysql-local/data`；业务库 `microtrip` |
| Redis | `Redis` | 6379 | `sc query Redis` | `net start Redis` | `net stop Redis` | 本机 3.0.504，**已是 Windows 服务** |
| Java 服务 | —（内嵌 Tomcat） | 3000 | `curl localhost:3000/actuator/health` | `java -jar` / `run-local.sh` | `taskkill /PID <pid> /F` | 无需独立 Tomcat |
| Java 服务（WinSW 服务） | `MicroTripServer` | 3000 | `sc query MicroTripServer` | `net start MicroTripServer` | `net stop MicroTripServer` | 开机自启；入口 `scripts/start-app.bat` |

> ⚠️ 端口冲突优先排查：`netstat -ano | findstr ":3306|:6379|:3000"`，再用 `tasklist /FI "PID eq <pid>"` 反查进程。

## 1. MySQL（服务名 `MySQL84`）

### 1.1 查看状态
```bash
sc query MySQL84                      # 服务状态（STOPPED / RUNNING）
net start | findstr /I MySQL          # 运行中服务列表里有没有 MySQL
netstat -ano | findstr :3306          # 3306 是否被监听 + 占用 PID
# 业务账号连通性
"C:\Program Files\MySQL\MySQL Server 8.4\bin\mysql.exe" -h127.0.0.1 -umicrotrip -pmicrotrip123 -e "SELECT 1;"
```

### 1.2 启动 / 停止
```bash
# 方式一（推荐，开机自启）：先停掉命令行旧实例，再起服务
net stop MySQL84
net start MySQL84

# 方式二（前台调试，关窗口即停）：
"C:\Program Files\MySQL\MySQL Server 8.4\bin\mysqld.exe" --datadir=D:/mysql-local/data --port=3306 --console --character-set-server=utf8mb4

# 停掉正在跑的命令行实例（root 免密，initialize-insecure 初始化）
"C:\Program Files\MySQL\MySQL Server 8.4\bin\mysqladmin.exe" -h127.0.0.1 -uroot shutdown
```
**一键注册 / 修正服务**：右键 `scripts/install-mysql-service.bat` → 以管理员身份运行。
脚本会检测服务是否指向正确的数据目录（`D:/mysql-local/data`）；若 winget 安装器留下的默认服务指向空库，会自动 `sc delete` 后重建，避免「启动了空数据库」。

### 1.3 常见排查
| 现象 | 原因 | 处理 |
|---|---|---|
| `ERROR 2003 (HY000): Can't connect ... (10061)` | 服务没起 / CLI 实例被回收 | `net start MySQL84` |
| `net start` 报「地址已在使用」 | 旧的命令行 `mysqld` 仍占 3306 | 先 `mysqladmin -uroot shutdown` 再起服务 |
| 连上了但看不到 `microtrip` 库 | 服务指向了安装器默认数据目录（空库） | 跑 `install-mysql-service.bat` 重建服务 |
| 启动失败 | 看错误日志 `D:/mysql-local/data/mysql_local.err` | 按日志修（端口/权限/数据目录损坏） |
| 中文乱码 | 客户端/连接字符集非 utf8mb4 | 连接加 `--default-character-set=utf8mb4`；库表已 utf8mb4 |

- root 默认**免密**（本机 `--initialize-insecure`）；业务账号 `microtrip` / `microtrip123`。
- 数据目录 `D:/mysql-local/data` **千万不要删**，里面是真实业务数据。

## 2. Redis（服务名 `Redis`）

### 2.1 查看状态
```bash
sc query Redis
net start | findstr /I Redis
"C:\Program Files\Redis\redis-cli.exe" ping        # 返回 PONG 即可
"C:\Program Files\Redis\redis-cli.exe" info server  # 版本/模式/端口
"C:\Program Files\Redis\redis-cli.exe" dbsize       # 当前键数
```

### 2.2 启动 / 停止
```bash
net start Redis
net stop Redis
# 客户端
"C:\Program Files\Redis\redis-cli.exe" -h 127.0.0.1 -p 6379
```

### 2.3 常见排查
| 现象 | 原因 | 处理 |
|---|---|---|
| `Could not connect` | 服务未起 | `net start Redis` |
| 想用新特性（Stream/ACL/RESP3） | 本机是 3.0.504，太老 | 升级 Memurai 或 WSL 装 Linux Redis；但本项目只用 KV+过期，**无需升级** |
| 重启后数据没了 | 没开持久化（RDB/AOF） | 本机开发无所谓；要持久化改 `redis.windows.conf` 开 `save`/`appendonly` 后重启服务 |

> 本机 Redis **本就是 Windows 服务**（进程以 `NETWORK SERVICE` 在 Services 会话运行，开机自启），不需要再注册。

## 3. Java 后端服务（内嵌 Tomcat，端口 3000）

> Spring Boot 内嵌 Tomcat，**不需要也不建议装独立 Tomcat**。部署即 `java -jar`。

### 3.1 查看状态
```bash
netstat -ano | findstr :3000                 # 是否在监听
curl -s http://127.0.0.1:3000/actuator/health # 健康检查（health/info 公开）
./scripts/health.sh                          # 项目自带健康检查脚本
```

### 3.2 启动
```bash
# 开发（H2，零依赖）
./scripts/run-local.sh h2 --bg
# 或指定 profile（mysql + redis）
./scripts/dev.sh mysql redis
# 或生产 jar
java -jar target/microtrip-server-*.jar --spring.profiles.active=prod,mysql,redis,https
# 一键拉起全家桶（自动确保 MySQL+Redis 起，再后台启动 App）
./scripts/start-all.sh              # full：MySQL + Redis + App（最贴近生产）
./scripts/start-all.sh h2           # 仅 App（H2 文件库，零依赖）
./scripts/start-all.sh --stop       # 停止后台 App（等同 run-local.sh --stop）
```
> Flutter 模拟器联调宿主机后端：用 `http://10.0.2.2:3000`（非 127.0.0.1）。

### 3.3 停止
```bash
# 前台：Ctrl+C
# 后台：先找 PID 再杀
netstat -ano | findstr :3000      # 记下 PID
taskkill /PID <pid> /F
```

### 3.4 常见排查
| 现象 | 原因 | 处理 |
|---|---|---|
| 3000 被占用 | 上一次没退干净 | `taskkill /PID <pid> /F` 或 `SERVER_PORT=3001 java -jar ...` |
| 接口返回空数据 / 统计为 0 | 轨迹同步 GPS 点键名用了 `points` 而非 `pts`（静默存 0 点） | 客户端改 `pts`；详见 `数据库操作指南.md` 契约坑 |
| profile 不生效 | 改了 yml 没重打包 | `./scripts/build.sh` 后用 jar 跑；或运行时 `--spring.profiles.active=` 覆盖 |
| 启动慢 / 连不上 MySQL | MySQL 服务没起 | 先 `net start MySQL84` |
| 日志看什么 | `application.log`（slf4j 输出，System.out 被吞） | 看项目根目录 `application.log` |

### 3.5 注册为 Windows 服务（WinSW，开机自启）
> 想要「开机即跑、进程被回收也不丢」，用 WinSW 把 App 包成真正的 Windows 服务。

**概念**：`run-local.sh --bg` 只是 `nohup` 后台进程，依赖你的终端会话；WinSW 是服务包装器，App 变成 `MicroTripServer` 服务，开机自启、崩溃自动重启（`<onfailure action="restart">`）。

**一键注册**（右键 `scripts/install-app-service.bat` → 以管理员身份运行）：
1. 自动从 GitHub 下载 WinSW（若 `scripts/WinSW.exe` 缺失），复制为同名 `microtrip-server.exe`；
2. 动态生成 `microtrip-server.xml`（写入项目绝对路径）；
3. `microtrip-server.exe install` + `start`，服务名 **`MicroTripServer`**。

**服务入口** `scripts/start-app.bat`：读/生成 `JWT_SECRET` → 关 HTTPS 强制 → 等待 MySQL(3306)/Redis(6379) 就绪（最多 60s）→ `java -jar` 前台运行（profile `prod,mysql,redis`）。

**日常管理**：
```bash
# 在 scripts/ 目录下用同名 exe 管理（install-app-service.bat 已复制好）
microtrip-server.exe stop      # 停止
microtrip-server.exe start     # 启动
microtrip-server.exe restart   # 重启
microtrip-server.exe uninstall # 卸载（含删除服务）
# 等价原生命令
net start MicroTripServer / net stop MicroTripServer
sc query MicroTripServer       # 看状态
```
- 日志：`.run/microtrip-server.out.log`（App 输出）、`microtrip-server.wrapper.log`（WinSW 自身）。
- 二进制 `WinSW.exe` / `microtrip-server.exe` 已在 `.gitignore` 忽略，不入库（需重跑 bat 重新下载）。
- 与 `start-all.sh` 区别：`start-all.sh` 适合你**手动**一键拉起全家桶调试；WinSW 适合**无人值守**常驻（开机自启）。两者 profile 一致（full = MySQL+Redis）。

## 4. 通用排障清单
1. **端口/进程**：`netstat -ano | findstr :<端口>` → `tasklist /FI "PID eq <pid>"`。
2. **服务**：`sc query <服务名>` 看状态；`net start/stop <服务名>` 启停。
3. **日志**：MySQL `D:/mysql-local/data/mysql_local.err`；Java `application.log`（运行目录）。
4. **一键体检**：`./scripts/health.sh`（Java）、`./scripts/backup.sh --local`（备份前先验证可连）。
5. **权限**：注册 / 删除 / 启停 Windows 服务需**管理员**；AI 沙箱无此权限，相关操作交你本机执行。
